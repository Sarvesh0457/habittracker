## ⚡ About The Project

Standard habit trackers feel like spreadsheets. **Protocol** is different. Built for a high-performance lifestyle, Protocol uses video game psychology to trick your brain into enjoying personal development. 

Whether you are trying to drink more water, code every day, or hit the gym, Protocol keeps you accountable through a beautifully designed, tactile interface that rewards consistency.

## ✨ Key Features

* **🎮 RPG Progression System:** Earn 50 XP for every completed task. Fill your progress bar, rank up through tiers (Novice → Grandmaster), and unlock achievements.
* **🔥 The "All-or-Nothing" Daily Protocol:** Streaks are tied to your *entire* day. Complete all your quests to keep the global streak alive. Miss one, and the streak breaks.
* **🗺️ 30-Day Consistency Map:** Visualize your historical progress with a GitHub-style contribution grid that dynamically updates based on your global streak.
* **🏆 Global Arena Leaderboard:** See how your XP stacks up against other top performers in the Arena.
* **⚡ Tactile & Responsive UI:** Built with premium "Soft Glass" aesthetics, micro-animations, audio feedback, and interactive confetti celebrations on level-ups.
* **💾 Zero-Friction Storage:** Runs entirely in the browser using intelligent `localStorage` management. No login required to start building habits.

## 🛠️ Built With

* **Frontend Framework:** React 18
* **Build Tool:** Vite
* **Styling:** Tailwind CSS v4
* **State Management:** React Hooks (`useState`, `useEffect`)
* **Data Persistence:** Browser LocalStorage API
* **Micro-Interactions:** `canvas-confetti` & HTML5 Audio
